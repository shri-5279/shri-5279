## Featured Projects

### 🔧 PipeLine AI
> *AI-powered CI/CD failure analysis using RAG and Agentic AI*

Transforms 40-minute debugging sessions into 30-second answers. Ingests build logs, traces failures through an LLM-powered reasoning engine, and surfaces root causes with actionable remediation steps — all without a human in the loop.

`AWS` `Python` `FastAPI` `LangChain` `Docker` `Terraform`

---

### ☁️ MCRP — Multi-Cloud Resource Platform
> *Unified cost and uptime monitoring across cloud providers*

Aggregates metrics from AWS and Azure into a single observability plane. Provides cost anomaly detection, uptime SLA tracking, and infrastructure health dashboards across environments.

`AWS` `Azure` `Terraform` `Python` `Postman`

---

### 🔗 IntelLink
> *AI-powered URL shortener with threat intelligence*

Beyond shortening — IntelLink scans destination URLs for malicious content in real time, tracks click analytics, and surfaces smart usage insights. Built for security-conscious teams.

`Python` `Redis` `PostgreSQL` `SQS` `Claude API`
